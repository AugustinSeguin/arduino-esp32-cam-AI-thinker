# 📡 Projet ESP32-CAM : Portail de Configuration Wi-Fi

Ce projet implémente un système de caméra de surveillance basé sur l’ESP32-CAM AI-Thinker.  
L’objectif principal est d’éliminer la nécessité de coder en dur les identifiants Wi-Fi, permettant un déploiement simple et un partage facile via un **Portail Captif de Configuration**.
